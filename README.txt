Website Biodata Rainhard
Tentang Website

Website ini dibuat untuk tugas sekolah sebagai media untuk memperkenalkan diri saya secara sederhana. Di dalamnya terdapat informasi tentang biodata, hobi, dan beberapa hal yang saya sukai.

Website ini dibuat dengan desain yang sederhana supaya informasi di dalamnya mudah dibaca dan nyaman dilihat.

Halaman Website

Website ini terdiri dari beberapa halaman:

Home — halaman utama dan perkenalan singkat.
Hobby — berisi hobi dan kegiatan yang saya sukai.
Review — berisi beberapa review atau hal yang ingin saya bagikan.
Teknologi yang Digunakan
HTML — untuk membuat struktur halaman website.
CSS — untuk mengatur tampilan, layout, dan desain.
Vercel — digunakan untuk melakukan deployment agar website bisa diakses secara online.
Tujuan Pembuatan

Website ini dibuat untuk memenuhi tugas sekolah sekaligus melatih kemampuan saya dalam membuat website menggunakan HTML dan CSS.
