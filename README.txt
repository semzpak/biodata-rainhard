# Owen's Lab – Student Starter Pack

## Files Included
- index.html — Your main HTML file.
- assets/ — Folder for images or additional files.

## How to Use
1. Open index.html in your browser.
2. Edit the file using any code editor (VS Code / Replit / Notepad++).
3. Start experimenting with headings, paragraphs, images, and links!

Happy coding!
